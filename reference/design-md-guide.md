# Guia de Seleção — DESIGN.md e Design Skills

Como escolher a referência visual certa para cada cliente.

---

## Parte 1 — DESIGN.md de Referência (awesome-design-md)

Escolha 1 DESIGN.md por cliente com base no posicionamento. Copie para a pasta do cliente como `DESIGN.md` e personalize com os dados do `brand-spec.md`.

### Por posicionamento

| Posicionamento do cliente | DESIGN.md recomendado | Visual resultante |
|---|---|---|
| Premium / high-ticket / consultoria | `linear` ou `stripe` | Minimalismo preciso, tipografia forte, escuro |
| Produtividade / método / organização | `notion` ou `airtable` | Clean, funcional, neutro, sem distrações |
| Tecnologia / SaaS / digital | `vercel` ou `cursor` | Preto/branco, precision, Geist-like |
| Educação / infoproduto acessível | `cal` ou `lovable` | Amigável, colorido moderado, approachable |
| Criativo / agência / portfólio | `runway` ou `clay` | Editorial, cinematográfico, atrevido |
| Finanças / investimentos / cripto | `coinbase` ou `binance` | Confiável, escuro, dados visuais |
| Lifestyle / personal brand | `superhuman` ou `raycast` | Premium dark, personalidade forte |
| Luxury / moda / alto padrão | `bmw` ou `bugatti` | Dark cinematic, pouquíssimo texto, imagens dominam |

### Por paleta preferida

| Paleta | DESIGN.md |
|---|---|
| Preto + branco + 1 acento | `vercel`, `linear` |
| Escuro com neon/gradiente | `elevenlabs`, `minimax` |
| Claro minimalista | `notion`, `cal` |
| Terracota / quente | `claude` |
| Azul institucional | `coinbase`, `stripe` |
| Roxo/lilas premium | `superhuman` |

## Parte 2 — Design Skills (awesome-design-skills)

Escolha 1 estilo visual por projeto. Use para definir a estética dos componentes, carrosseis e landing pages.

Os 5 mais relevantes para o seu contexto:

### `bold`
**Quando usar:** Produto de impacto, infoprodutor que vende transformação, lançamentos de alto volume, público jovem ou nichado.
**Visual:** Tipografia enorme, contraste extremo, pouco texto, imagem de impacto.
**Combina com DESIGN.md:** `elevenlabs`, `minimax`, ou custom.

### `clean`
**Quando usar:** Cliente premium, consultoria, produto high-ticket, quando a sofisticação é o diferencial.
**Visual:** Muito espaço negativo, tipografia refinada, cores sóbrias.
**Combina com DESIGN.md:** `linear`, `stripe`, `vercel`.

### `contemporary`
**Quando usar:** Personal brand moderno, infoproduto de nicho criativo, educação adulta.
**Visual:** Editorial, grid assimétrico, mix de sans e serif, fotografia real.
**Combina com DESIGN.md:** `notion`, `cal`, `clay`.

### `bento`
**Quando usar:** Apresentação de features, carrossel de benefícios, social media com múltiplos pontos.
**Visual:** Grid de blocos tipo Apple, ícones limpos, hierarquia por tamanho de célula.
**Combina com DESIGN.md:** `linear`, `airtable`.

### `colorful`
**Quando usar:** Produto para educação/jovens, nicho de saúde ou bem-estar, marca descontraída.
**Visual:** Paleta vibrante, energia alta, tipografia amigável.
**Combina com DESIGN.md:** `lovable`, custom.

## Como usar na prática

### Para landing page:
1. Escolhe o DESIGN.md pelo posicionamento → copia para pasta do cliente
2. Escolhe o design skill pelo tipo de entrega → usa como instrução de estilo no impeccable/landing-page-guide-v2

### Para social media:
1. Usa o brand-spec.md do cliente como referência de cor e tipografia
2. Escolhe o design skill para definir o visual dos cards
3. Mantém o mesmo estilo em todas as peças da semana/mês

### Para lançamento:
1. Define 1 DESIGN.md + 1 design skill no início da campanha
2. Usa os dois em TODOS os materiais do lançamento (LP + social + animação + deck)
3. Consistência é o que faz a campanha parecer profissional
