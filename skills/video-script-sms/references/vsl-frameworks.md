# VSL Frameworks — Base White Label

> Referência genérica de VSL de alta conversão.
> Aplicável a qualquer produto, cliente ou nicho.
> Para roteiros específicos de produto, consulte o arquivo do cliente.

---

## O QUE É UM VSL DE ALTA CONVERSÃO

VSL (Video Sales Letter) é o roteiro de venda por vídeo. Não é um vídeo educativo. Não é um tutorial. É pressão na direção certa — mover alguém de indiferente para comprador.

**Regra central:** cada segundo precisa ganhar o próximo. Se um segundo não tem função, corta.

---

## DURAÇÃO POR TIPO DE PRODUTO

| Ticket | Duração ideal | Motivo |
|--------|--------------|--------|
| Low ticket (até R$150) | 7–10 min | Decisão rápida, baixa fricção |
| Mid ticket (R$150–R$500) | 12–20 min | Precisa construir mais valor |
| High ticket (R$500+) | 20–45 min | Convencimento profundo, objeções complexas |

**Regra:** quanto mais baixo o ticket, mais cirúrgico o VSL. Cada minuto a mais é risco de perder antes do CTA.

## ESTRUTURA DE ATOS — VSL PADRÃO

```
ATO 1 — HOOK (primeiros 10% do tempo)
ATO 2 — AGITAÇÃO (10% a 30%)
ATO 3 — VIRADA (30% a 40%)
ATO 4 — SOLUÇÃO / DEMO (40% a 70%)
ATO 5 — PROVA (70% a 80%)
ATO 6 — OFERTA (80% a 90%)
ATO 7 — URGÊNCIA + GARANTIA (90% a 95%)
ATO 8 — CTA FINAL (95% a 100%)
```

---

## ATO 1 — HOOK

O gancho decide se o VSL será visto ou fechado. Primeiros 10 segundos são críticos.

### Regras absolutas
- Nunca começar com apresentação pessoal ("Oi, eu sou o [nome]...")
- Nunca começar com contexto — contexto vem depois
- O espectador precisa sentir que é com ele nos primeiros 10 segundos
- Uma ideia. Uma tensão. Nada mais.

### 9 tipos de hook comprovados

**1. CONTRARIAN** — desafia o que todo mundo acha que sabe
```
"Todo mundo te diz pra postar todo dia. Isso está matando seu alcance."
```

**2. DADO CHOCANTE** — número que força o cérebro a continuar
```
"82% dos agentes de IA que você compra não sabem quem você é."
```

**3. PERGUNTA COM TENSÃO** — incomoda quem já tomou aquela decisão
```
"Você tem o ChatGPT. Mas ele sabe quem você é?"
```

**4. AFIRMAÇÃO BOLD** — declaração que demanda reação
```
"Agente de IA genérico não é agente. É chatbot com crachá."
```

**5. STORY OPENER** — puxa para narrativa imediata
```
"Eu quase não lancei isso. Deixa eu te contar por quê."
```

**6. EMPATIA** — abre com a dor do espectador, não com a mensagem
```
"Você está cansado de conteúdo sobre IA que não te ensina a fazer nada."
```

**7. BEFORE/AFTER** — mostra o gap de transformação
```
"6 meses atrás eu operava tudo sozinho. Hoje tenho dois agentes fazendo isso."
```

**8. DESAFIO** — tom provocador que cria curiosidade
```
"Vou criar um agente do zero agora. Se eu passar de 5 minutos, você vai embora."
```

**9. CONFISSÃO** — vulnerabilidade que desarma a defesa
```
"Eu quase não lancei isso. Achei que era complicado demais pra ensinar."
```

### Hooks para VSL de produto de IA (específico)
```
"Abra com identificação de dor com precisão cirúrgica"
"Se você já tentou [X] e não conseguiu [Y]..."
"Nunca abra com apresentação pessoal"
"Primeiro minuto: espectador precisa sentir que você está falando com ele"
```

---

## ATO 2 — AGITAÇÃO

Amplia a dor. Mostra o custo de não resolver. Não culpa o espectador — culpa a ferramenta, o mercado ou o contexto.

### Regras
- A agitação nunca culpa o espectador — remove resistência
- Mostra o custo de continuar igual (tempo perdido, dinheiro, oportunidade)
- Usa especificidade: "toda vez que você abre uma conversa nova" > "frequentemente"
- Termina com o espectador sentindo que o problema é insustentável

### Tipos de agitação por nicho

**Peso do operacional:**
```
"Você resolve tudo. Você é o gargalo. Sem você, para."
```

**Fragmentação de conteúdo:**
```
"Você consome conteúdo todo dia sobre [tema] e não sai com nada funcionando."
```

**Ferramenta genérica:**
```
"Você abre. Explica tudo de novo. Recebe resposta genérica. Fecha. Repete."
```

**FOMO de mercado:**
```
"Enquanto você pondera, a concorrência implementou e está operando."
```

---

## ATO 3 — VIRADA

O momento em que existe uma saída. Transição de dor para esperança. Apresenta o mecanismo único.

### Regras
- A virada não é sobre o produto — é sobre a nova perspectiva
- Deve ter um nome (mecanismo único): "Super Agente", "DNA Criativo", "Kit de Ignição"
- Tom: esperança + credibilidade. Não euforia.
- Diferencia claramente da solução genérica que o espectador já tentou

### Estrutura da virada
```
[O problema existe por causa de X]
[Mas existe uma forma diferente]
[Essa forma tem um nome]
[E eu vou te mostrar]
```

---

## ATO 4 — SOLUÇÃO / DEMO

Apresenta o produto como o veículo perfeito para a transformação.

### Regras
- Benefício > Feature. O que muda na vida > o que a ferramenta faz
- Demo ao vivo é o tipo mais forte de prova para produto de IA/tech
- Uma ideia por cena — se tem duas, são duas cenas
- Mostrar o resultado antes de explicar o processo

### Empilhamento de valor (stack)
Apresentar entregáveis um a um, cada um adicionando percepção de valor antes do preço.

```
Entregável 1 → valor percebido sobe
Entregável 2 → valor percebido sobe mais
Entregável 3 → ...
[Preço revelado quando o valor percebido já está alto]
```

---

## ATO 5 — PROVA

Tangibiliza que a solução funciona para pessoas reais.

### Hierarquia de prova (mais forte para mais fraca)
1. **Dogfooding** — "Eu uso isso na minha operação hoje"
2. **Prova de bastidor** — prints reais, tela ao vivo, sem produção excessiva
3. **Depoimento específico** — nome + resultado numérico + antes/depois
4. **Volume** — número de clientes/alunos com especificidade
5. **Autoridade institucional** — parceiros, menções, prêmios

### Regra de ouro da prova
```
❌ "Centenas de clientes satisfeitos"
✅ "347 clientes. 89% com resultado na primeira semana."

❌ "Ótimo produto, recomendo!"
✅ "Estava faturando R$15k. Em 60 dias, passei para R$47k. — Fernanda R., SP"
```

**Prints de WhatsApp/Telegram batem depoimento produzido** — bastidor real gera mais confiança.

---

## ATO 6 — OFERTA

Apresenta o que está incluído, o preço e as condições.

### Regras
- Preço sempre DEPOIS da prova — nunca antes
- Âncora de preço: mostrar o valor comparativo antes do preço real
- Listar entregáveis concretos antes de revelar o número
- Uma oferta clara — sem opções demais

### Ancoragem de preço
```
"Agência cobra R$3.000 pra implementar isso.
Freelancer cobra R$1.500.
Aqui: R$87. Pagamento único. Você faz sozinho em 16 aulas."
```

---

## ATO 7 — URGÊNCIA + GARANTIA

### Urgência — tipos válidos
```
ESCASSEZ REAL: "Últimas X vagas. Turma fecha sexta."
PREÇO DE FUNDADOR: "R$87 no lançamento. Sobe depois."
FOMO DE MERCADO: "A vantagem competitiva diminui conforme mais gente implementa."
TEMPORAL: "Bônus disponível apenas nessa semana."
```

**Nunca usar urgência falsa** — público percebe e perde confiança.

### Garantia — reversão total de risco
```
"7 dias incondicional. Você entra, acessa tudo.
Se não for o que eu disse — devolvo tudo. Sem pergunta.
O risco é meu."
```

Quanto mais agressiva a garantia, mais ela remove fricção de compra.

---

## ATO 8 — CTA FINAL

Uma instrução. Uma ação. Nenhuma ambiguidade.

### Regras
- CTA é instrução, não sugestão: "Clica no botão" > "Você pode clicar abaixo"
- Nunca terminar com "é isso" ou "espero ter ajudado"
- Terminar com ação ou com a frase mais forte do VSL
- Visual: botão visível, URL clara, ou QR code

```
✅ "Clica no botão. Acesso imediato."
✅ "O risco é meu. O agente é seu. Clica."
❌ "Espero ter ajudado! Qualquer dúvida é só chamar!"
```

## 5 PREMISSAS DE VSL — MODELOS TESTADOS

Cada premissa define o arco emocional inteiro do VSL. Escolher antes de escrever uma linha.

### PREMISSA A — SIMPLIFICAÇÃO RADICAL
**Quando usar:** produto técnico com público que tem medo de não conseguir
**Arco:** "Eu não sei nada de técnico. E tenho resultado. Você também consegue."
**Gatilho central:** Identidade — "se ele conseguiu sem saber, eu consigo"
**Tom:** igualitário, sem superioridade
**Inimigo:** a crença de que é difícil demais

### PREMISSA B — EMPATIA + BARULHO
**Quando usar:** mercado saturado de conteúdo, público cansado de promessa
**Arco:** "Você está cansado. Eu sei. Hoje é diferente."
**Gatilho central:** Empatia — validar antes de vender
**Tom:** acolhedor, sem julgamento
**Inimigo:** o feed infinito que ensina sem entregar

### PREMISSA C — DOGFOODING + AUTORIDADE
**Quando usar:** produto que o criador usa no próprio negócio
**Arco:** "Eu não vendo o que não uso. Eu ensino o que roda na minha operação."
**Gatilho central:** Autoridade por uso real
**Tom:** direto, confiante, sem precisar convencer
**Inimigo:** cursos teóricos que não saem do papel

### PREMISSA D — FOMO DE MERCADO
**Quando usar:** produto ligado a tendência ou vantagem competitiva temporal
**Arco:** "A janela está aberta. Quem entrar primeiro leva vantagem."
**Gatilho central:** Medo de perda + urgência real
**Tom:** urgente, mas não desesperado — sério
**Inimigo:** a inércia e a espera pelo "momento certo"

### PREMISSA E — STORYTELLING PESSOAL
**Quando usar:** produto que nasceu de experiência real do criador
**Arco:** "Eu quase não lancei isso. Mas o que aconteceu me fez mudar de ideia."
**Gatilho central:** Vulnerabilidade + reciprocidade
**Tom:** íntimo, confessional, câmera próxima
**Inimigo:** a falta do método que o criador também não tinha no começo

## 12 GATILHOS MENTAIS — REFERÊNCIA RÁPIDA

| Gatilho | Ativa | Exemplo |
|---------|-------|---------|
| Escassez | Medo de perder | "Últimas 7 vagas" |
| Urgência | Pressão temporal | "Cada dia sem resolver é [custo real]" |
| Prova social | Comportamento de manada | "347 clientes. 89% renovam." |
| Autoridade | Deferência a quem sabe | "Uso isso pra operar minhas 3 empresas" |
| Reciprocidade | Impulso de retribuir | "Aqui está [valor] sem custo" |
| Contraste | Avaliação comparativa | "Agência: R$3.000. Aqui: R$87." |
| Antecipação | Desejo pelo que não chegou | "Na semana que vem revelo o método" |
| Curiosidade | Lacuna de informação | "O erro que 90% cometem e parece certo" |
| Especificidade | Credibilidade | "4 minutos e 23 segundos" > "menos de 5 minutos" |
| Identidade | Pertencimento | "Para quem já passou do básico" |
| Dor × Prazer | Fuga e busca | Dor ativa, prazer confirma |
| Quebra de padrão | Atenção pelo inesperado | "Eu não vou te convencer. Vou te mostrar." |

### Combinações mais poderosas
```
Escassez + Prova Social: "Últimas 5 vagas. As outras 45 foram em 72h."
Contraste + Especificidade: "Agência cobra R$3.500/mês. Aqui R$87 único."
Autoridade + Dogfooding: "Uso no meu negócio todo dia. Ensino o que funciona."
Identidade + Urgência: "Para quem quer resultado real. A janela fecha domingo."
```

## INTELIGÊNCIA DE MERCADO — PADRÕES DE CONCORRENTES (CATEGORIA IA)

### O que todos os VSLs de alta conversão em IA fizeram

**1. Nunca abrem com apresentação pessoal**
Todos abrem na dor ou na promessa. Zero "oi, eu sou o [nome]".

**2. Inimigo comum = ChatGPT/IA genérica**
O vilão não é o espectador. É a ferramenta genérica que prometeu e não entregou.

**3. Simplificação radical é obrigatória**
"Não precisa saber programar" aparece em todos. Remove a barreira técnica antes que vire objeção.

**4. Dogfooding bate depoimento**
Mostrar usando no próprio negócio converte mais do que qualquer depoimento de terceiro.

**5. Especificidade cria credibilidade**
"136 agentes, 11 squads, 21 workflows" > "muitos agentes". Número específico parece mais verdadeiro.

**6. Prints de bastidor > produção polida**
WhatsApp screenshot, tela de Telegram, terminal aberto — bastidor real gera mais confiança que vídeo produzido.

**7. Preço sempre depois da prova**
Sem exceção. Prova primeiro, preço depois.

**8. Garantia agressiva remove o último obstáculo**
15 a 30 dias incondicional é padrão. Quanto mais agressiva, mais remove fricção.

### O que nenhum concorrente fez (oportunidade)
**Demo ao vivo com cronômetro em tempo real.**
Todos prometem facilidade. Nenhum prova na câmera enquanto o espectador assiste.

## FRAMEWORKS DE COPY PARA CADA ATO

### PAS — Problema, Agitação, Solução
Melhor para: hook e agitação de VSLs curtos
```
PROBLEMA → nomeie a dor sem rodeio
AGITAÇÃO → custo de continuar com o problema
SOLUÇÃO → saída específica e crível
```

### 4Ps — Picture, Promise, Prove, Push
Melhor para: VSLs de landing page, alto impacto
```
PICTURE → cena mental — leitor dentro do problema ou solução
PROMISE → promessa central específica
PROVE → dados, casos, lógica que valida
PUSH → urgência ou consequência — por que agir agora
```

### BAB — Before, After, Bridge
Melhor para: storytelling com transformação
```
BEFORE → situação atual/dor detalhada
AFTER → situação desejada/resultado específico
BRIDGE → como chegou lá — a oferta/produto
```

### Feature-Benefit-Meaning
Melhor para: apresentação de entregáveis na oferta
```
FEATURE → o que é / como funciona
BENEFIT → o que isso gera para o usuário
MEANING → o que significa na vida real
```

## REGRAS DE LINGUAGEM ORAL (ROTEIRO FALADO)

- Escrever como se fala — sem vírgulas em excesso
- Frases máximo 10–12 palavras por vez
- Usar reticências para pausas naturais: "E sabe o que é pior..."
- Frases longas constroem tensão. Frases curtas impactam. Alternar.
- Verbos de ação, não de estado: "dobra seu resultado" > "é uma solução para"
- Nunca voz passiva: "você recebe" > "será entregue"
- Ler em voz alta antes de entregar — se travar, reescrever

```

□ Agitação mostra o custo de não resolver?
□ Virada tem mecanismo único com nome?
□ Demo ou prova é específica e crível?
□ Entregáveis foram empilhados antes do preço?
□ Preço vem depois da prova?
□ Urgência é verdadeira (não falsa)?
□ Garantia remove o risco do espectador?
□ CTA é uma instrução exata — uma ação, uma direção?
□ Duração bate com o ticket do produto?
□ Leu em voz alta e não travou?
```
