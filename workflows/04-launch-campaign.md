## Fluxo completo

### FASE 1 — BASE DA CAMPANHA (Semana -4)

```
huashu Core Asset Protocol
→ extrai logo, cores, fontes, screenshots do produto
→ grava brand-spec.md

huashu Direction Advisor
→ 3 direções visuais para a campanha
→ escolhe 1 → tudo seguirá esse estilo

designer-skills /ux-strategy:benchmark
→ analisa 3 lançamentos similares
→ identifica oportunidade de diferenciação

content-strategy-sms
→ pilares da campanha:
   Educação → Autoridade → Método → Desejo → Prova → Urgência

content-calendar-sms
→ cronograma completo:
   Semana -3: Educação + problema
   Semana -2: Autoridade + método
   Semana -1: Desejo + prova + antecipação
   Dia 0: Abertura de carrinho
   Dias 1-7: Urgência + last call
```

### FASE 2 — LANDING PAGE DE VENDAS (Semana -3)

```
impeccable shape + craft + polish
→ LP com foco em transformação do produto
→ prova social desde o rascunho (sem placeholder)
→ urgência real (data ou bônus limitado)
→ garantia proeminente

huashu 5D critique → fixes
impeccable audit → fixes
→ LP publicável
```

### FASE 3 — AQUECIMENTO (Semanas -3 a -1)

**Por semana, produzir:**

Semana -3 (Educação e problema):
```
Peça 1: Carrossel educativo sobre a dor
  hook-writer-sms → carousel-writer-sms → card-news-generator-v2 → caption-writer-sms

Peça 2: Post de autoridade
  hook-writer-sms → post-writer-sms → caption-writer-sms

Peça 3: Reel educativo
  video-script-sms → caption-writer-sms

content-repurposer-sms → adapta tudo para outras plataformas
```

Semana -2 (Autoridade e método):
```
Peça 1: Carrossel do método/processo
Peça 2: Thread de bastidor
Peça 3: Reel de autoridade
```

Semana -1 (Desejo e prova):
```
Peça 1: Carrossel de transformações/resultados
Peça 2: Post de antecipação (abre lista VIP)
Peça 3: Reel de depoimento ou prova
```

### FASE 4 — LANÇAMENTO (Dia 0 ao Dia 7)

**Assets de alto impacto:**
```
huashu-design → animação de abertura de carrinho (MP4 + BGM)
huashu-design → deck de vendas para live (HTML + PPTX)
huashu-design → protótipo da área de membros (clicável)
```

**Copy de lançamento:**
```
Dia 0 — Abertura:
  hook-writer-sms → hook de abertura
  post-writer-sms → post de lançamento
  video-script-sms → roteiro do vídeo/live de abertura

Dias 1-5 — Sustentação:
  post-writer-sms → depoimentos, perguntas frequentes, bastidor
  caption-writer-sms → legendas

Dia 6 — Last call:
  hook-writer-sms → hook de urgência
  post-writer-sms → post de fechamento

Dia 7 — Encerramento:
  thread-writer-sms → thread de encerramento
  post-writer-sms → post de última hora
```

### FASE 5 — PÓS-LANÇAMENTO (Semana +1)

```
performance-analyzer-sms → o que converteu mais
content-pattern-analyzer-sms → padrões de conteúdo que performaram
audience-growth-tracker-sms → crescimento durante a campanha
optimization-advisor-sms → o que replicar no próximo lançamento
```

## Checklist de lançamento

- [ ] LP publicada e testada em mobile + desktop
- [ ] Formulário/checkout testado com compra real
- [ ] Animação de abertura pronta
- [ ] Deck de live pronto
- [ ] Calendário de posts aprovado
- [ ] Todos os assets de marca em brand-spec.md
- [ ] Calendário do time (se houver) alinhado
- [ ] Meta ads criativos (se aplicável) prontos
- [ ] E-mail de abertura agendado
- [ ] Página de obrigado configurada
