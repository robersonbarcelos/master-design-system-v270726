# Production Rules — Aurum Lingerie

> Leia este arquivo ANTES de escrever qualquer copy ou prompt visual.
> Aplicar a cada entrega — sem exceção.

---

## 00 | REGRAS CRÍTICAS

1. **Idioma:** inglês — SEMPRE em todos os posts, sem exceção
2. **Handle:** SEMPRE `@lingerieaurum`
3. **Paleta:** usar APENAS a paleta v2.0 — preto `#0A0A0A`, cream `#FAF7F2`, dourado `#B8860B`, rosa `#f5d9e8`
4. **Tom:** dark luxury — elegante, emocional, direto. Nunca genérico, nunca promocional de atacado
5. **Logo area:** sempre declarar em prompts — `[LOGO]` no rodapé, área limpa sólida
6. **Produto:** nunca recriar ou descrever o produto no prompt — `preserve exactly all product details`
7. **Textos no Freepik:** sempre revisar no Canva após geração (Freepik comete erros de soletração)

---

## 01 | GATILHO PRÉ-COPY

Antes de escrever copy, responder:
1. **Qual nível de funil?** — TOPO (identidade/desejo) / MEIO (conexão/processo) / FUNDO (conversão)
2. **Qual produto?** — Panties / Set / Robe / Coleção geral
3. **Qual template?** — 02 Fade Full Bleed (Stories) / 04 Split Editorial (Feed) / Outro
4. **Qual CTA?** — "Shop now — link in bio 👇" / "Shop the collection" / Nenhum (TOPO puro)

## 04 | WORKFLOW DE PRODUÇÃO DE PROMPTS

### Fluxo obrigatório
1. Propor 3 ideias de visual (contexto, template, hierarquia de texto)
2. Aguardar aprovação do usuário
3. Propor 3 variações de headline/copy
4. Aguardar aprovação das headlines
5. Gerar JSON apenas após aprovação

### Regras de prompt Freepik
- Usar `[LOGO]`, `[MODELO]`, `[ÂNCORA]`, `[HEADLINE]`, `[SUBHEADLINE]`, `[CTA]` como placeholders
- NUNCA usar `@img1` / `@img2`
- NUNCA descrever características do produto — apenas: `preserve exactly all product details, fabric, colors and model appearance`
- Escrever o prompt de forma fluida e contínua
- Incluir tipografia com: `text reads exactly '[texto]'`

### Negative prompt padrão
```
altered product, recreated fabric, changed colors, modified model, bokeh, blur, soft focus,
CGI, cartoon, overprocessed, watermark, text touching edges, text inside logo bar, harsh flash
```
