# Production Rules — Intus Hub

> Leia este arquivo ANTES de escrever qualquer copy.
> Nunca produza sem passar pelo Gatilho Pré-Copy.

---

## 00 | REGRAS CRÍTICAS

1. **Tom:** educador estratégico — nunca guru motivacional, nunca hype
2. **Dados antes de opinião:** nunca afirmar sem ancoragem em dado real
3. **HUB:** sempre em dourado `#F0B429` — NUNCA em azul
4. **Fundo:** sempre escuro — NUNCA branco
5. **Syne:** sem text-stroke, sem outline, sem sombra — fill puro
6. **Campanha SA:** paleta laranja/preto — não misturar com institucional azul/dourado
7. **Preço:** sempre âncora R$997 antes de R$87,90 / 6x R$16,50

---

## 01 | GATILHO PRÉ-COPY (obrigatório)

Antes de escrever copy, responder:
1. **Qual pilar?** — IA Aplicada / Anti-ruído / Prova real / Educação de estrutura / Conversão
2. **Qual formato?** — Reel / Carrossel / Estático / Stories
3. **Qual nível de funil?** — Topo (descoberta) / Meio (educação) / Fundo (conversão)
4. **Há dado concreto disponível?** — Usar dado real ou não publicar dado
5. **Tom de Diego para este pilar:**
   - IA Aplicada → lúdico, dinâmico, humor técnico
   - Cripto/DeFi → analítico, fundamentado, sério, sem sorriso
   - Negócios → estratégico, aspiracional
   - Educação → didático, acolhedor

## 02 | VOCABULÁRIO APROVADO

| ❌ Nunca usar | ✅ Sempre usar |
|---------------|----------------|
| "Ganhe dinheiro dormindo" | "Aspira opera 24/7 — eu só entro pra decidir" |
| "Revolucionário" | Dado concreto + mecanismo real |
| "Simples e fácil" sem provar | "5 minutos — é o tempo real pra ativar" |
| Hype de guru | Tom de fundador que usa o que ensina |
| "50 agentes prontos" | "1 agente real com memória persistente" |
| Promessa financeira vaga | Prova com nome real (Denys, Arcanjo) |
| "ChatGPT com superpoderes" | Explicação do mecanismo: IDENTITY.md + memória |

## 04 | REGRAS DE PRODUTO

- **Aspira e Clóvis:** tratar como colaboradores reais, não como "bots" ou "ferramentas"
- **Kit de Ativação:** sempre mencionar quando falar de setup — é o diferencial de produto
- **Memória persistente:** maior diferencial técnico — usar como hook educativo
- **"5 minutos" e "sem programar":** usar com responsabilidade — é verdade, não hype
- **Preço:** âncora R$997 sempre antes de revelar R$87,90 ou 6x R$16,50
- **Garantia:** 7 dias incondicional, sem perguntas — sempre presente em FUNDO

---

## 05 | REGRAS VISUAIS PARA SOCIAL

- Fundo: `#0a0a0a` ou `#111111` — nunca branco
- Headline: Syne 800 — branco `#F0F4FF` ou laranja `#E84000`
- Laranja como acento — não preencher grandes áreas
- JetBrains Mono para tags, preços, dados técnicos
- Logo V2 (símbolo isolado) para criativos quadrados
- Logo V1 (horizontal) para banners e stories
- Foto Diego: iluminação azul-elétrico + telas ao fundo (padrão) ou campanha laranja
